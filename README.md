# 河图·地理信息平台 — 易用性优化原型

面向北大荒集团的非 GIS 专业业务人员的河图平台易用性优化交互原型。

## 在线预览

访问 GitHub Pages：`https://arthurvictor0923.github.io/informationforGeographic/`

## 本地预览

直接在浏览器中打开 `index.html`。

## 原型内容

- **四模块导航**：数据资产 / 地图服务 / 要素图层 / 专题地图
- **引导系统**：欢迎弹窗、工作流横条、模块说明卡片、帮助面板、空状态引导、Toast 通知链
- **弹窗向导**：上传数据、发布服务、注册服务、创建要素图层、创建专题地图
- **术语白话化**：GIS 技术术语 → 业务人员可理解的自然语言
- **空状态设计**：四个模块各有专属空状态引导卡片，点击 Header「📭 空状态」按钮可切换预览

## 设计规范

- 品牌色：`#2f54eb`（与内部页面统一）
- 术语体系：Layer A（界面白话）/ Layer B（Hover 提示）/ Layer C（高级模式原名）
- 引导体系：Layer 1（全局走马灯）/ Layer 2（模块横幅）/ Layer 3（空状态卡片 + 反馈链）
