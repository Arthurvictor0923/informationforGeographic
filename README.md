# 河图·地理信息平台 — 易用性优化原型（拆分版）

面向北大荒集团的非 GIS 专业业务人员的河图平台易用性优化交互原型。纯静态 HTML/CSS/JS，零构建依赖，GitHub Pages 托管。

## 在线预览

访问 GitHub Pages：`https://arthurvictor0923.github.io/informationforGeographic/`

## 本地预览

直接打开 `index.html`（数据资产首页），或任一模块页。

## 页面结构（拆分版）

| 文件 | 说明 |
|------|------|
| `index.html` / `数据资产.html` | 数据资产（首页 / 入口，同一页面） |
| `地图服务.html` | 服务资源与发布 |
| `要素图层.html` | 要素图层 |
| `专题地图.html` | 专题地图 |
| `任务中心.html` | 异步任务中心（数据入库 / 服务发布） |
| `要素图层编辑器.html` | 要素图层样式设计器（一套数据 → 主体图层 + 表达层，独立场景） |
| `制图规范原型.html` | 制图规范（样式规范 / 符号规范：组织级制图标准资产库） |
| `地图编辑器优化原型.html` | 专题地图设计器（独立原型，V3） |
| `common.js` / `common.css` / `tailwind.css` | 共享逻辑 / 设计系统 / 预编译样式 |

顶部导航共 6 个模块：数据资产 · 地图服务 · 要素图层 · 专题地图 · 制图规范 · 任务中心。

## 核心特性

- **异步任务中心**：上传 / 发布在后台处理，顶栏铃铛 + 独立「任务中心」页跟踪进度，失败可重试
- **数据状态体系**：入库中 / 待发布 / 已发布 / 失败 等状态 Tag，任务完成自动联动
- **引导收口**：欢迎弹窗 + 帮助面板，强调「异步、可并发、任务中心跟踪」
- **跨页持久化**：localStorage 保存任务、数据状态与「查看结果」跳转闭环

## 设计规范

- 品牌色（内部页）：`#2bbaa0`（hover `#1cd6b4`，active `#0f947c`）
- Tailwind 预编译静态 `tailwind.css`（源 `input.css` + `tailwind.config.js`，改类后 `npx tailwindcss@3.4.17 -i input.css -o tailwind.css --minify`）
- 零外部依赖（地图编辑器原型除外，其使用 Leaflet CDN + 天地图瓦片）
