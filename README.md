# 河图·地理信息平台 — 易用性优化原型（改版分支）

面向北大荒集团非 GIS 专业业务人员的河图平台易用性优化交互原型。纯静态 HTML/CSS/JS，零构建依赖，GitHub Pages 托管。

## 在线预览

访问 GitHub Pages：`https://arthurvictor0923.github.io/informationforGeographic/`

## 本地预览

打开 `index.html`（自动进入数据资产），或直接打开任一模块页。**必须保持同目录下的 JS / CSS / lib 文件夹相对位置**，无需安装任何构建工具。

## 页面结构（改版分支，2026-10-12）

| 文件 | 说明 |

## 核心特性

- **异步任务中心**：上传 / 发布在后台处理，顶栏铃铛 + 独立「任务中心」页跟踪进度，失败可重试
- **数据状态体系**：入库中 / 待发布 / 已发布 / 失败 等状态 Tag，任务完成自动联动
- **服务序列管理**：管理员维护序列（CRUD + 默认样式模板组 + 升降序 + 批量套用）
- **要素图层编辑器**：图层保存后可重开编辑，服务选择支持跨数据、多协议、多服务引用
- **跨页持久化**：localStorage 保存任务、数据状态、发布记录、图层与地图设计，刷新不丢

## 设计规范
