## 本期（2026-10-13）调整要点

- **发布服务**：保留两步；类型改为「中文名 + 协议缩写 + 用途」；只填一个面向用户的名称（默认带数据名，内部标识系统生成）；按已有类型与元信息预选协议；MVT 默认选已有主键、支持别名／原名搜索；参数提供系统默认 / 常用层级 / 点聚合。
- **注册服务**：四个平台入口，区分「服务平台 / 网络来源 / 服务类型」；只填一个显示名称，记录 ID 自动生成；不自动猜测协议。
- **添加数据**：保留三步；普通 CSV/Excel/TSV 免填坐标系；TIFF/GeoTIFF 增加「解析像素直方图」开关（减少入库处理时间）。
- **统计与详情**：按已有记录汇总，缺失值显示「—」，不补演示值；详情补回数据四至、视图范围、坐标单位、原栅格行列/波段、数据源、元数据操作历史等原字段。
